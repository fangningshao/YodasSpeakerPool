# YodasSpeakerPool

A curated, richly-annotated multi-speaker dataset for zero-shot voice cloning and multi-speaker TTS applications. Built from Emilia-YODAS and annotated with state-of-the-art audio understanding models.

## Dataset Overview

**YodasSpeakerPool** contains approximately **7,600 unique speakers** with high-quality audio samples and comprehensive metadata:

- **3.4K Chinese speakers** (Emilia-YODAS Chinese - all shards)
- **4.2K English speakers** (Emilia-YODAS English - first 8 shards)

Each speaker sample:
- Duration: 4-15 seconds of clean speech
- Format: WAV audio files
- Annotation: Comprehensive metadata generated by **Gemini 2.5 Flash**

## Annotation Schema

Each speaker is annotated with the following aspects using Gemini 2.5 Flash:

| Field | Type | Description |
|-------|------|-------------|
| `asr` | String | Transcribed text from the audio (what the speaker is saying) |
| `noise_level` | Integer (0-3) | Audio quality: 0 = clear recording, 1 = slight background noise, 2 = moderate noise, 3 = loud noise |
| `naturalness` | Integer (0-3) | Voice naturalness: 0 = mechanical/robotic, 1 = somewhat natural, 2 = natural, 3 = very natural human voice |
| `language` | String | Language code (e.g., "en-US", "zh-CN", "zh-TW", "ja-JP", "fr-FR") |
| `dialect` | String | Specific dialect or accent (e.g., "American English", "British English", "普通话", "粤语", "上海话", "四川话", "天津话") |
| `style` | String | Speaking style (e.g., "chatting", "news", "podcast", "storytelling", "lecture", "presentation", "reading", "singing") |
| `emotion` | String | Primary emotion (e.g., "neutral", "happy", "sad", "angry", "surprised", "fearful", "excited", "calm", "passionate") |
| `maybe_ai` | Integer (0-1) | AI detection flag: 1 = possibly AI/synthetic voice or reminds of AI assistant, 0 = certainly human |
| `speaker_description` | String | Detailed 200-500 word English description covering voice characteristics, speaker demographics, speaking style, audio quality, suitable use cases, and unique vocal features |

> **Note:** The audio understanding quality is determined by the capabilities of the annotation model (Gemini 2.5 Flash). We may update the dataset with improved annotations as models advance in the future.


## Creating Your Own Pool

We provide the complete pipeline for extending to other languages or datasets:

### Requirements

It is recommended to create your own conda environment then follow requirements.txt.

```bash
pip install torchaudio google-generativeai gradio pandas tqdm
```

### Usage

1. **Set up your Gemini API key:**

```bash
echo "YOUR_GEMINI_API_KEY" > gemini-key.txt
```

2. **Create a speaker pool from your dataset:**

Assuming that `/path/to/your/dataset/` is your path which contains subfolders, such as the Emilia-YODAS shards:

```bash
python dataproc/create_speaker_pool_gemini.py \
  --input_dir "/path/to/your/dataset/*" \
  --output_dir "data/my_speaker_pool" \
  --min_duration 4.0 \
  --max_duration 15.0
```

The script will:
- Sample one audio per speaker (within duration range)
- Analyze each sample with Gemini 2.5 Flash
- Generate comprehensive metadata (JSON format)
- Create summary statistics

3. **Explore with the visualization tool:**

```bash
python demo.py
```
